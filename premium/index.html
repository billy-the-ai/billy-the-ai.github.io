Questions

What happens when the free answers run out? Billy says so once, then goes quiet until midnight UTC rather than repeating himself. Moderation, tickets, protection and every other feature keep working exactly as normal — only the AI answers pause.
Is it per server or per account? Per server. Premium applies to the one server you buy it for, and the allowance is counted per server so one busy community can never spend another's share.
Can I cancel? Any time. The server drops back to the free plan at the end of the period, and nothing you have set up, taught Billy, or logged is deleted.
Does Billy stop working without premium? No. Free is a real plan, not a trial. Most servers never need more than it.
Where do I actually pay? Inside Discord. Run /premium buy in your server and Discord takes the payment on its own screens, with the card you already have on file. This site never sees, handles or stores card details.
How do I turn it on after paying? You don't. Billy is told the moment the payment goes through and switches premium on by himself — and he checks again every hour, so a purchase made while he was restarting still lands. Run /premium compare to see the plan and today's answer count.
